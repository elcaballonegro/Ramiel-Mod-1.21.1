# Ramiel-Mod-1.21.1
Adds Ramiel from the Rebuild of Evangelion to Minecraft as a new boss mob, incorporating its forms, attacks, destruction, and phases. Also adds a craftable railgun for players, but it's expensive.

I will be truthful: this mod is a side project and my first attempt at designing a workflow for Claude. A lot went into the main setup for Claude before actual workshopping took place, and I had to manually tweak files to use for setup; i.e., I didn't just drop a few PNGs and call it a day.
